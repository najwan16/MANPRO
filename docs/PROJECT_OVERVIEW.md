# Project Overview — SiMagang MVP v3

## Root problem

Mahasiswa sulit mengetahui kesesuaian keterampilan dengan tuntutan posisi magang dan kurang kesempatan mencoba tugas industri secara terarah **sebelum magang**. Temuan wawancara awal menunjukkan gap praktik, perbedaan tools, dan ketidakpastian persiapan. Data belum membuktikan kesediaan membayar atau peningkatan peluang lolos rekrutmen.

## Segment awal

Mahasiswa bidang Sistem Informasi/Teknik Informatika yang ingin mencoba peran Junior System Analyst. Tidak eksklusif semester 3–6; segmentasi ditentukan **jobs-to-be-done**, bukan umur atau semester.

## Positioning

"Coba tugasnya, terima penilaian, lalu buktikan perkembangan hasil kerja sebelum melamar magang." Berbeda dalam fokus pada diagnosis dan evidence hasil revisi; bukan klaim bahwa Rakamin atau alternatif gratis tidak dapat memiliki fitur serupa.

## Sasaran MVP

- Menampilkan free task yang benar-benar dinilai.
- Menjual satu paket yang dapat diperagakan lengkap: latihan dokumen terstruktur + feedback + revisi.
- Menampilkan conversion path berupa demo checkout, tanpa mengklaim pendapatan.
- Menyajikan bukti perubahan isi artefak V1/V2 (hasil bisa tidak meningkat).

## Bukan cakupan

Lowongan magang / ATS, perusahaan mitra nyata, pembayaran produksi, verifikasi identitas, integrasi real-time tools lain, penilaian generatif atas dokumen bebas, sertifikasi profesi, klaim placement atau gaji.
