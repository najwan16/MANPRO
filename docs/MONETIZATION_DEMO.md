# Monetization Demo — No Real Transaction

## Conversion sequence

Public catalog → System Analyst detail → free practical task → honest feedback → illustrative comparison sample → optional paid package preview → demo identity → checkout mock → activated local entitlement → project briefing → work + feedback + revision → report/portfolio/certificate demo.

## Limits and customer promises

- Yellow DEMO banner visible on all screens.
- Checkout declares **"SIMULASI PEMBAYARAN — TIDAK ADA TRANSAKSI NYATA"** prominently.
- QRIS, VA, E-wallet options are **display labels only**. No QR code, transfer destination, payment gateway, card or bank credential collection.
- The pay CTA says **"Aktifkan Akses Demo"**, not "Pembayaran sukses" or "Uang telah diterima".
- Price Rp19.000 is test hypothesis and cannot be asserted as validated willingness to pay.
- Offline browser entitlement is not secure and must not be used for public commercial production.
- Show investor an end-to-end route but **do not present mock transaction count as actual revenue**.
- Example before/after document is labeled **Contoh**; live portfolio is computed from user submitted answers.

## UX copy anti-patterns to avoid

Do not claim "kamu belum siap magang" based on three free choices, "jaminan diterima kerja", "sertifikasi kompetensi resmi", "mitra PT Nusa Digital Solusi", or "simulasi ini telah dibayar" after a mock checkout.
