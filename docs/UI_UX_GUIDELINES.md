# UI / UX Guidelines

## Visual identity

- Primary navy `#17305C`; deeper navy `#0D2042`; accent `#2D5B91`; bright accent `#2378E3`.
- Secondary backgrounds `#F5F8FD` and `#EAF2FC`, neutral white `#FFFFFF`.
- Positive `#167958`, informational blue, warning amber. Scores may decrease; do not force green when not earned.
- Sans-serif system/Inter fallback, meaningful hierarchy, rounded 9–20px, generous whitespace, 1180px main content max width.
- Hero uses navy gradient and original CSS-generated dashboard illustration, **not** a real-company screenshot.

## Accessibility / interaction

- Native semantic links, buttons, labels, form inputs, fieldsets; keyboard focus visible.
- Tap targets ~40–49px; color supported by icons/text labels (not color alone).
- Mobile: cards stack, desktop two-column detail/checkout; workspace sidebar becomes horizontally scrollable list.
- One primary CTA per decision area. Action labels reflect behavior: "Coba Tugas Gratis", "Aktifkan Akses Demo", "Kirim Revisi V2".
- Honest copy: "fiktif", "demo", "preview", and "bukan sertifikasi profesi" always explicit.
- Inline feedback near scoring; comparison in V1/V2, avoid manipulating or hiding weak results.

## Conversion UX

Give value first. Do not gate free feedback behind login. Show sample premium deliverable and explicit pricing. Checkout should be optional, nonaggressive, and accurately communicate that no real payment occurs. Premium benefits are concrete outputs, not speculative career outcomes.

## Responsive checks

Test 1440x900, 1024x768, 768x1024, 390x844; no horizontal overflow, CTA visibility, readable feedback and tables, export controls accessible.
