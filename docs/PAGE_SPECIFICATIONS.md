# Page Specifications — Feature Acceptance

## Landing

Hero with free entry CTA, optional catalog CTA, authentic product explanation; three-stage learning value, simulations catalog and illustrative before/after. Never use fake testimonials or real-company logos.

## Explore

Client-side search by role, company, skill, tool; category and status filter. Empty state and reset filter; four cards, only System Analyst active. All cards link to informative detail but unavailable products cannot be purchased.

## Detail

Case and supervisor identified fiktif, price hypothesis, skills/tools/deliverable, sample User Story, full inclusions, CTA free + checkout demo only for active project. No dead buttons.

## Free Task

Three structured decisions with native `<select>` semantics and required selection. On submission, deterministic score with per-dimension feedback. The result must not be described as full work readiness.

## Free Result & Offer

Honest score irrespective of level, strengths and gap on tested decisions, the student's three submitted choices, example V1/V2 document marked as illustration. Offer can be dismissed and result remains free.

## Login Demo

Name and **example email only**; no password input; explicit local-only identity warning. Persist per browser. Destination restored from sessionStorage.

## Checkout Demo

Large warning "SIMULASI PEMBAYARAN — TIDAK ADA TRANSAKSI NYATA". Payment methods are illustrations. Activation grants only local, owner-scoped entitlement. No card/QR/account collection.

## Welcome / Workspace

Case briefing. Three ordered tasks. Each task: structured editor, autosave on input, live document preview, optional Markdown export, V1 submit → rubric feedback → V2 editor → comparison. Task 2 additionally links diagrams.net for optional independent use; external result not auto-evaluated. Show stage status and affordances for continuing.

## Dashboard

Resume attempt, task completion, demo checkout count for the current email, free result and reset action. Clearly label local mode.

## Performance Report

Only after all tasks completed with V1 and V2. Weighted averages, raw task scores, delta, rubric feedback, portfolio navigation, export Markdown.

## Portfolio

Side-by-side V1/V2 artifacts, actual user decisions, changed field count; export `*.md`. This is practice evidence, not validated professional portfolio.

## Certificate

Issue only if all six submissions exist and weighted V2 >=70. Download SVG or print. Contains DEMO watermark/disclaimer and unverified ID.

## UX states

Empty result, locked task, unauthenticated redirect, missing entitlement redirect, score ineligible notice, field validation errors (native browser + toast), loading/static server errors and reset confirmation.
